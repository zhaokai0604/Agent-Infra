# ThreshCore Agent UI 改版目标（对话式运维）

> 慢慢改：每阶段独立可演示、可回滚；不改后端 API 契约。

## 总目标

**外观**：登录后对话居中、Composer 为主、侧栏轻量。  
**能力**：保留并强化工具执行、演练预览、二次确认、审计、巡检、负载——比纯聊天多一层「可证明的执行」。  
**受众**：软件杯演示 + 日常运维；Agent 页对话化，日志/审计等 Tab 只换壳不窄表。

## 成功标准（改版完成时）

- [x] Agent 页：欢迎语 + 大 Composer + 消息区 max-width 780px 居中
- [x] 顶栏无拥挤监控条；性能/巡检/安全在右侧上下文栏
- [x] 侧栏：Agent 区（新建对话、技能、历史）+ 折叠「运维中心」
- [x] 技能页：运维工具可用/不可用网格
- [x] 对话页：证据条（工具、AWM、溯源）+ 流式状态提示

## 阶段

1. 布局与视觉令牌（`agent-workspace.css`）

3. 右侧上下文栏与 RuntimeModeBar
4. 「自主运维只读」或全面检查 → 修复计划 → 确认预览
